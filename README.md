# ML Playground

An interactive machine learning curriculum built with Next.js, TypeScript, and Bun. The first lesson explores linear regression and gradient descent in the browser.

```sh
bun install
bun run dev
```

Open http://localhost:3000. Run `bun run build` to generate a static site in `out/`, or `bun run typecheck` to check TypeScript. All simulation data and calculations stay in the browser.
